# Knowledge Base

This folder stores learning notes for the fire engineering portfolio.

Each topic file should use labelled references and avoid treating learning notes as compliance advice.

## Sections

- `01_fire_dynamics` - fire science fundamentals.
- `02_fire_engineering_practice` - UK building fire engineering and fire strategy context.
- `03_international_and_industrial_practice` - non-UK and industrial/insurance context.
- `04_fds_modelling` - FDS, Smokeview, post-processing, and model credibility.
- `05_evacuation_modelling` - evacuation modelling and ASET/RSET concepts.
- `06_consultancy_skills` - reporting, registers, QA, and client-facing communication.
