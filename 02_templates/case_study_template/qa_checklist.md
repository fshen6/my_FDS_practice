# QA Checklist

## Setup

- [ ] Case folder structure complete
- [ ] FDS input file saved
- [ ] Software versions recorded
- [ ] Case brief exists
- [ ] Disclaimer included or referenced

## Input Review

- [ ] Units checked
- [ ] Geometry checked
- [ ] Mesh recorded
- [ ] Fire assumptions recorded
- [ ] Ventilation assumptions recorded
- [ ] Material assumptions recorded
- [ ] Output devices defined before running
- [ ] Slice outputs defined before running
- [ ] File names are clear and consistent

## Run Review

- [ ] Simulation runs without fatal errors
- [ ] `.out` file reviewed
- [ ] Warnings noted
- [ ] HRR output checked
- [ ] Run status recorded in `model_log.md`

## Results Review

- [ ] Smokeview geometry checked
- [ ] Smoke/temperature behaviour reviewed
- [ ] Device outputs plotted
- [ ] Figures have captions
- [ ] Figures include units where relevant
- [ ] Results are linked to the design question

## Reporting Review

- [ ] Assumptions included
- [ ] Limitations included
- [ ] Claims match evidence
- [ ] No compliance/safety overclaiming
- [ ] References included
- [ ] Public disclaimer included

## Final Case Review

- [ ] Brief, registers, model log, QA checklist, report, and website summary are internally consistent
- [ ] Any unresolved blockers are listed
- [ ] Case status is clearly marked
